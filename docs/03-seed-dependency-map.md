## C. Практическая схема восстановления (по имеющимся [В]/[К])
1. **48 бит** через структуры (п.1, 1b, 4): перебор 2^48, фильтры по нескольким наблюдаемым структурам/слайм-чанкам; многократно ускоряется решёткой по линейному состоянию LCG.
2. **Проверка версии**: структурные позиции одинаковы во всех версиях (числа идентичны, docs/02 §5), **страхолды и биомы — нет** (docs/02 §4.5, doc 04).
3. **16 старших бит** (64-бит seed): (а) хэш `obfuscateSeed` (65536 SHA-256), (б) декорация `setDecorationSeed` (Xoroshiro, 64 бита), (в) Overworld-климат (Xoroshiro).
4. Seed из генератора UI лежит в образе 48-бит LCG (п. A): после нахождения 48 бит старшие 16 выводятся почти однозначно (проверка соотношения LCG верх↔низ).
