# План: Blender-аддон «MC Worldgen» (исполнение по потокам работ)

Спецификация: `docs/superpowers/specs/2026-10-02-blender-worldgen-addon-design.md`. Контракт между потоками: `libmcgen/include/mcgen.h`, `libmcgen/README.md`.
Метод исполнения: параллельные агенты по потокам работ, каждый в своей зоне файлов; координатор (основной ассистент) коммитит, интегрирует и прогоняет ворота; каждый этап принимается только по измеренному совпадению с настоящими чанками.

## Волна 1 (запущена 2026-10-02)
| Поток | Зона | Вехи | Ворота |
|---|---|---|---|
| W1 Рельеф | `libmcgen/src` (кроме mesh), `cli`, `tests`, `Makefile`, `docs/blender/terrain.md` | M1 каркас+биомы → M2 density/шумы → M3 заполнение шумом → M4 версии/пресеты/настройки | G1, G2 |
| W4 Ресурсы/меши | `blender/mcgen_addon/{assets,mesh,render}`, `libmcgen/src/mesh`, `docs/blender/assets-mesh.md` | M1 ресурсы → M2 C-мешер → M3 Blender-слой → M4 редактирование → M5 LOD/слияние | G7 (части), G8 |
| W5 Аддон/сборка | `blender/mcgen_addon/{__init__,core,ui,blender_manifest.toml}`, `libmcgen/build.py`, `tools/build_extension.py` | M1 мост+макет → M2 ресурсы пользователя → M3 UI/операторы → M4 сборка → M5 настоящая библиотека | G0 |
| W6 Эталоны | `tools/gt`, `run/gt`, `docs/blender/ground-truth.md`, `accuracy.md` | M1 изоляция датапаком → M2 миры → M3 diff/ворота → M4 помощь W1 | инфраструктура G2–G6 |

## Волна 2 (после G2 у W1)
* W2 Поверхность (G3): правила `material_rule`/SurfaceSystem, бедрок/глубинный сланец, полосы бесплодных земель.
* W3 Пещеры/каньоны/руды (G4): карверы, aquifer-жидкости, жилы.
## Волна 3
* Декорации (G5): ≈60 типов фич, ≈273 размещённых, FeatureSorter, деревья, изоляция по одной фиче.
* Постройки (G6): structure_set, jigsaw, NBT-шаблоны, повороты, Beardifier.
## Интеграция
* Аддон ↔ настоящая библиотека (G7), производительность, жадное слияние/LOD, релиз по платформам, документация, публикация.
